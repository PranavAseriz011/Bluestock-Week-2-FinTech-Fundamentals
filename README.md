## 📌 Project Overview

This repository contains my Week 2 prerequisite assignments for the Bluestock FinTech internship. The work focuses on understanding financial markets, analysing company financial statements, extracting data from REST APIs, learning basic software architecture, and exploring how data analytics supports FinTech businesses.

The objective is to develop foundational financial-domain knowledge and practical skills for working with real-world data analytics projects.

## 🎯 Learning Objectives

* Understand stock market fundamentals and financial terminology.
* Analyse company financial statements using Excel.
* Extract and transform API data using Python.
* Understand REST APIs, JSON, HTTP methods, and query parameters.
* Visualise application data flow through a software architecture diagram.
* Explore Indian brokerage platforms and the financial market ecosystem.
* Practise Git and GitHub for version control and project documentation.

## 📈 Assignment Highlights

### 1. Stock Market Fundamentals

Prepared a summary of basic stock market concepts, including exchanges, market capitalisation, financial ratios, and corporate actions.

### 2. Financial Statement Analysis

Prepared a financial analysis report and Excel workbook based on Infosys financial statements.

### 3. REST API Data Extraction

Used Python to retrieve JSON data from a public API, inspect the response, and export records to CSV.

### 4. Software Architecture

Created a data-flow diagram illustrating how information moves through a web application, backend services, a database, and an analytics dashboard.

### 5. FinTech Business Research

Explored Indian brokerage platforms, Demat accounts, NSDL, CDSL, SEBI, the trading lifecycle, settlement, and potential business applications of data analytics.

## 💡 Key Takeaways

* Financial-domain knowledge helps analysts interpret business data correctly.
* APIs provide a programmatic way to retrieve structured data.
* CSV files make API data convenient to explore and analyse.
* Software architecture helps explain how data travels between systems.
* Data analytics can support operational monitoring, customer experience improvements, and business decision-making.
* GitHub provides version history and a central location for project documentation.
