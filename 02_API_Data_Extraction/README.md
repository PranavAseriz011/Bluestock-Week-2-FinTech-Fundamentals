# API Data Extraction — Bluestock Week 2

## Objective

Learn REST APIs, HTTP methods, JSON responses, and CSV data extraction using Python.

## API Used

JSONPlaceholder — a public practice API.

Endpoint: <https://jsonplaceholder.typicode.com/posts>

## Concepts Covered

- REST API fundamentals
- GET requests to retrieve data
- POST requests to submit data
- HTTP status codes
- JSON response handling
- Query parameters
- API authentication basics
- Converting JSON data into CSV using Pandas

## Tools and Libraries

- Python
- Requests
- Pandas
- VS Code

## Files

- `api_extraction.py` — Python script for API requests and data extraction.
- `api_data.csv` — Extracted API records in CSV format.

## Results

- Successfully retrieved 100 post records.
- Inspected JSON responses.
- Filtered records using the `userId` query parameter.
- Tested a POST request using the practice API.
- Exported API data to CSV.

## Note

JSONPlaceholder is a testing API. POST requests simulate creating records and do not permanently store them.

## Learning Outcome

Developed a basic understanding of API integration and structured data extraction using Python.
